work

  • ray tracer in c++ 2026

    recursive ray tracer built following ray tracing in one weekend: monte carlo sampling, diffuse, metal and dielectric materials, stochastic antialiasing, a defocus-blur camera and gamma correction. writes raw ppm, no dependencies.

  • mini compiler 2026

    lexer, recursive descent parser, typed ast and x86-64 codegen (at&t syntax) for a minimal c subset. no llvm. the output assembles, links, and returns the right exit code.

  • matrix openmp benchmark 2025

    1000×1000 integer matrix multiply, parallelised over the outer loop with #pragma omp parallel for and timed against a serial baseline with omp_get_wtime(). 4.25s to 1.12s, a 3.79x speedup on 16 threads (4 p‑cores + 8 e‑cores). haven't isolated how much of the gap from linear comes from static scheduling across uneven cores, cache behaviour, or thermal throttling.

setup

i can use my entire setup without a trackpad or a mouse.

linux

i installed arch linux in the first semester of my college. my peers said, "are you mad that you wiped windows and installed arch? how do you even use this thing?" at that time, i wasn't using claude code or codex, so i had to manually click pictures of errors and ask gemini what i should do. it took me a lot of hours to set up that thing, but all that headache and irritation gave me a setup which i can use trackpad-free.

neovim

stop using vs code. i have never installed vs code in my life; i have been using neovim as my first editor. it is faster to use: you don't have to move your cursor to code every time you want to make changes. you can customize it however you want, which is underrated imo. use tmux and lazyvim; there are a ton of tools like that. i think it's at least worth giving it a try.

mine runs on lazy.nvim with about 30 plugins, including telescope, treesitter, harpoon, oil, blink.cmp, mason and nvim-dap.

no trackpad or mouse

  • vim keys run the windows: super+hjkl focuses, super+shift+hjkl resizes, super+ctrl+hjkl moves.
  • wl-kbptr puts a letter grid on the screen. type the letters for a cell, narrow it down, and the pointer clicks there. ydotool covers the rare click nothing else can.
  • super+/ opens a searchable cheatsheet of every keybind, read live from the compositor.
  • zsh, tmux and qutebrowser all run on vim keys too.

scripts in bin/

  • zen locks me into one window. every global keybind goes dead until i leave, and notifications go quiet.
  • red is a shader that turns the screen fully red for night work.
  • afk keeps the laptop awake for a set time, like afk 9h.
  • saver, balance, performance, game are power modes on the function keys, built on cpupower, intel p-state and tlp. powermode shows which one is on.
  • battery-low-warning is a systemd service that waits on upower events and closes its own warning the moment the charger goes in.
  • waybar-pixelshift moves the bar a few pixels every 10 minutes so nothing burns into the oled.
  • dpms, lock, screen-wake are the safety net for the idle ladder (dim, lock, screen off, suspend), so the screen always comes back.
  • cdbg builds a single c/c++ file and runs it under asan and ubsan, valgrind, gdb, rr or hyperfine.
  • dsa opens my dsa practice layout on one key, turns on do-not-disturb and logs the session.
  • pomo is a terminal pomodoro that silences notifications during focus blocks.
  • ytm, cmus-open pull audio into my music folder and open it in cmus.
  • keys, hlset are the keybind cheatsheet and a helper for changing hyprland settings from scripts.

blockers

  • no-shorts blocks youtube shorts and instagram reels for good while the rest of both sites keeps working. it's a browser policy plus a force-installed extension, with tests.
  • social-block null-routes instagram, linkedin, x and reddit between 22:00 and 06:00 on systemd timers.

small things

  • a tap on the power button wakes the laptop instead of shutting it down.
  • super+shift+t ocrs any region of the screen with tesseract and puts the text on the clipboard.
  • screenshots with hyprshot, a dropdown terminal, and a window overview on super+a through quickshell.
